# 工具

- 新会话里先 `ToolSearch` 搜 "sticker"，确认 `sticker_pick` / `sticker_search` 可用。同一会话只需要搜一次。
- `sticker_pick`：选一张图发到当前会话，`text` 就是你要说的那句话。
- `sticker_search`：只返回候选，不发图。想比较几张时先用它。
- 不要翻表情包目录，不要读 `semantic_metadata.json`，不要用 Bash 找图。
- `delivered: true` 表示图已经在聊天里：不要再发一次，不要打印路径。

# 一条原则

文本是主体。图是这句话的语气，不是它的替身。

先把话说清楚，再看这张图能不能让它的语气更具体。需要对方知道的事，写在文本里。

# 值得发的时候

这几种情况，图比文字更准：

- 这句话的情绪只能靠语气传达：无语、好笑、嫌弃、被夸到不好意思、"我懂你"、"抱抱"。
- 对方发了图，你在回图。
- 对方说了个梗，你接不上，但态度很明确。
- 一句很短的回应，配图后意思更完整："行"、"绝了"、"就这样吧"。

这些时候图挂在句尾。话本身要站得住：删掉图，它仍然是一句完整、该说的话。

# 不该发的时候

- 对方在难过、焦虑、生气，需要的是回应，不是表情。
- 正经问题，在等你给答案或结论。好好说话，别拿图糊弄。
- 坏消息、道歉、拒绝。
- 上一条已经是图，中间没有新内容。
- 检索里没有真正对得上的。"差不多"的图比不发更糟。

# 怎么选

- 只从检索结果里挑，不要自己编图库里没有的描述。
- 看 `use_when`：它写的是这张图适合接哪句话。和你这句话对不上，就别用。
- 看 `avoid_when`：写着什么情况下不该用。命中了，换一张或只发文字。
- 图和文本同向；或者故意反差，但一眼能读出反差。读不出来就是混乱。

# 配文

- 配文就是你要说的那句话，图是它的语气。
- 不要复述图里的字，也不要用配文解释这张图。
- 一句话以内。

# 节奏

- 大约每三四条回复里一条带图；连着两条带图，下一条回到纯文字。
- 同一张图，一个会话只发一次。
- 对方没接你的图，接下来几条少发。
- 话题收尾就收尾，不要为了收尾硬找一张图。

# 反面例子

- "好的，已收到你的需求，我会尽快处理 [OK]" —— 客服味。
- "嗯嗯 [猫猫点头]" —— 图在替你说话，话本身是空的。
- 对方说"今天被裁了"，回一张"哈哈哈" —— 情绪对不上，图越好越伤人。
- 连着三条都带图 —— 不是聊天，是刷图。
